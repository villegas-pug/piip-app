# PIIP Frontend

1. Conserva el shell, rutas y estilos de PIIP Web 2.
2. Usa puertos de datos y adaptadores HTTP; los mocks quedan para demo/pruebas.
3. Mantén los seis catálogos en `PIIP_CATALOGS` y prueba su paridad.
4. Consulta unidades y ámbitos desde la API.
5. No muestres acciones fuera del rol y ámbito efectivo.
